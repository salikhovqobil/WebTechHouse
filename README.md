# Tech House - Ecommerce Prototype

## Project Overview
Tech House is a multi-page ecommerce prototype for a household appliances store. The site is built with HTML5, CSS3 (Flexbox/Grid), and vanilla JavaScript. It is designed to match BTEC Unit 6 requirements and includes reusable layout sections, product browsing, cart storage, and checkout validation.

## Features
- Home page with hero, categories, featured products, promotions, and benefits
- Categories page with filters (brand, price, rating), sort, and search
- Product details page with gallery, specs, and related products
- Cart with quantity updates, remove actions, and localStorage persistence
- Checkout form validation and order summary
- Contact page with form, map placeholder, and FAQ accordion

## Sitemap
- Home (`index.html`)
  - Categories (`pages/categories.html`)
    - Product Details (`pages/product.html?id=101`)
  - Cart (`pages/cart.html`)
    - Checkout (`pages/checkout.html`)
  - Contact (`pages/contact.html`)

## How to run
1. Open `index.html` in a modern browser.
2. Navigate using the menu and category links.
3. Use the cart and checkout to test the prototype behavior.
